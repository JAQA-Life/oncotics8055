Oncotics Browser AI edition for Hostinger Web/Cloud hosting.

AI runs on the visitor's WebGPU device with included, self-hosted Qwen weights and WebLLM runtime. No external AI API or separate inference backend. Public evidence APIs remain enabled. Preserves original Oncotics site, OHIF, globe and four imaging model packs.

Download **Oncotics-Hostinger-Upload.zip** for direct File Manager upload. **Oncotics-Browser-AI-Complete-Project.zip** includes source, build tools, model assets, tests and documentation. Read **HOSTINGER-UPLOAD.md** before deploying.

This approved browser rewrite replaces the MiroFish engine workflow; it does not execute either original Python engine. The engine version remains on main. Research only; no medical validation is claimed. Each browser profile stores its own evidence and runs.

The release is published only after provenance/workflow tests, asset-integrity checks and real browser/model inference checks pass. Exact results and hashes accompany the ZIPs.
